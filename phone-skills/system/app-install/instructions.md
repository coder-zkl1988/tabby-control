## 官方应用市场安装

- 普通“打开 App”任务先尝试 `AWAKE` 打开目标 App；只有结果明确表明未安装时才进入安装流程。任务明确要求打开商店详情、安装或更新时，直接进入官方市场流程。
- 官方市场流程的第一步固定使用 `AWAKE value:"store:<目标包名>"`。无论当前停在哪个页面，都不要先 `BACK`、`CLICK`、退出当前页或返回桌面。
- 安装任务禁止使用缺少目标包名的 `system:app_store`；必须使用 `store:<目标包名>`，让系统直接打开该应用的官方详情页。
- 不得打开浏览器、搜索引擎、网盘或第三方 APK 下载站。
- 商店只打开首页时再搜索目标应用；核对应用名称、开发者、图标及可见包名，避开广告位、极速版和仿冒条目。
- 系统安装确认出现时再次核对目标应用。涉及商店登录、付费、家长确认或未知来源授权时 `CALL_USER`。
- 安装完成后使用目标包名 `AWAKE`，并以目标 App 真正进入前台作为成功后置条件。
- 官方市场缺失、候选不唯一或无法确认目标时停止并报告，不能选择第一个候选项。
