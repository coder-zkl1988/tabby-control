# 回复消息子技能（私信 + 评论/@回复）

适用任务：查看消息、回复私信、给指定联系人发消息，或**回复别人在我笔记下的评论、回复@我的消息**。

## 安全规则
- 私信和评论回复都是对外发送内容。若用户没有明确指定对象（联系人/哪条评论）和回复内容，先 `INFO` 询问。
- 陌生人私信、评论回复可能有频率和额度限制，遇到限制直接报告，不要反复发送。

## 消息页结构（先认清要去哪一栏）
小红书底部“消息” tab 里通常分几栏，根据任务选对入口：
- **评论和@**：别人评论了我的笔记、或 @了我 → 走“回复评论/@”流程。
- **私信**：一对一聊天对话 → 走“回复私信”流程。
- 赞和收藏、新增关注：仅通知，一般不需要回复。
- 当前账号没有私信时，页面会显示“暂时没有消息”和“你可能感兴趣的人”。推荐关注按钮不是消息内容，回复任务不得点击关注。
- 右上角 `+` 菜单包含创建群聊、群聊广场、添加好友、圈子广场和扫一扫。只有用户明确要求这些功能时才打开；创建群聊、添加好友和加入圈子会改变账号状态，进入最终确认前必须核对对象。

### 0. 进入消息页
- 如果当前不在小红书，先 `action:AWAKE value:"小红书"`。
- 点击底部导航“消息”。
- 任务是回复评论/@ → 点击“评论和@”入口；任务是回复私信 → 进入私信对话列表。
- 用户要求找联系人或历史对话时可使用顶部搜索；不要用右上角 `+` 的“添加好友”替代搜索现有对话。

验证信号：
- 顶部标题为“消息”或类似文字。
- 页面显示赞和收藏、新增关注、评论和@、私信对话列表等。

## 回复评论 / @（我的笔记收到的评论）

### 1. 进入评论和@
- 在消息页点击“评论和@”。
- 列表每行显示：评论者头像/昵称、评论内容、对应的笔记缩略图。

### 2. 找到要回复的评论（先判断这条能不能回复）
- 按用户指定的评论者昵称或评论内容定位；没指定时，从最新一条**可回复**的评论开始处理。
- **只有同时具备“赞”和“回复”操作入口的评论才是可回复的真实评论。** 如果某条只显示“该内容已删除/评论已删除/内容不存在”、没有评论正文、也没有赞/回复按钮，它就是已失效的评论，**不可回复，直接跳过**，不要点它、更不要反复尝试。
- 找不到可回复的评论时向上滑动加载更多；连续两次找不到 `ABORT value:"失败：没有可回复的评论"`。

### 3. 回复
- 点击该条评论的“回复”入口（或评论行），弹出输入框/进入笔记评论区。
- 点击“回复”后页面可能延迟 2～3 秒才弹出输入框；先 `WAIT value:3` 再判断，不能连续点击同一按钮。等待后仍无输入框时只允许再点击一次并再次等待，仍无变化就报告失败。
- 点击输入框 → `TYPE value:"回复内容"` → 点发送。
- 用户没给回复内容时先 `INFO value:"要回复《评论内容摘要》什么？"`。
- 用户只给了整体语气或范围、没有逐条给文本时（例如“帮我用轻松口吻回复一下评论区”），按下面的规则自己生成每条回复：
  - 禁止用“感谢分享~”“感谢支持~”“感谢关注~”一类固定寒暄开头，不同评论不能套用同一句式起手。
  - 每条回复要接得住该条评论的具体内容或情绪，长度、用词、有没有语气词都要有变化，不要每条都用相同收尾。

验证信号：
- 优先识别小红书原生提示“你的回复已发布”；该提示出现且输入框关闭/清空时，代表服务端已接受回复。
- 如果进入了原笔记评论区，也可以用自己的完整回复文本、作者标识或回复气泡作为二次验证。
- 通知卡片的正文或缩略图可能只打开图片预览，不能据此断言发送失败，也不要反复点击寻找评论树。
- 没看到发布提示、自己的回复文本或明确发送状态时，报告“发送状态未确认”，绝不能再次发送同一内容。

**失效处理（重要，避免死循环）：**
- 点击后若弹出“该内容已删除/已删除/内容不存在”之类的 toast，说明这条评论已被删除，**无法回复**。立即放弃这一条，在 key_process 记 `已跳过：<评论者>（内容已删除）`，改为处理下一条可回复的评论；**绝不对同一条重复点击尝试**。
- 如果这是用户唯一指定的目标评论且已删除，`ABORT value:"失败：该评论已被删除，无法回复"`。

### 4. 多条处理
- 任务要求回复多条时，处理完一条返回评论和@列表，在 key_process 记 `已回复 i：<评论者>`（或 `已跳过`），再处理下一条，不要重复回复同一条。

## 回复私信

### 1. 进入消息页
- 已在消息页时，进入私信对话列表（若刚才在“评论和@”，先返回消息页主界面）。

### 2. 找到联系人
- 在私信列表中寻找用户指定昵称或备注。
- 找不到时向上滑动列表加载更多。
- 如果有搜索入口，可使用搜索联系人。
- 连续两次找不到时 `ABORT value:"失败：没有找到该联系人"`。

### 3. 进入对话
- 点击目标对话行。
- 验证顶部出现对方昵称，底部出现输入框。

### 4. 输入并发送
- 点击底部输入框。
- 输入用户提供的 reply_text。
- 点击发送按钮。
- 如果没有明确发送按钮，观察键盘确认键或输入框右侧按钮。

验证信号：
- 右侧出现自己发送的消息气泡。
- 输入框清空或显示发送状态。

## 失败处理
- 发送失败：重试一次。
- 陌生人额度限制或账号异常：`CALL_USER`。
- 对话不存在：报告失败并建议用户提供更准确昵称。
