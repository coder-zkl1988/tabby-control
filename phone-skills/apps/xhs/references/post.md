# 发布笔记子技能

适用任务：发布小红书图文、文字笔记或帖子。

## 安全规则
- 发布属于对外公开操作。若用户没有明确给出标题、正文、图片来源或是否确认发布，先 `INFO` 询问。
- 进入最终发布前，如果用户只是要求“帮我编辑/准备”，不要点击最终发布按钮。
- 内容审核、账号异常、登录页出现时，使用 `CALL_USER` 或 `ABORT`。

## 推荐流程

### 1. 打开发布入口
- 如果当前不在小红书，先 `action:AWAKE value:"小红书"`。
- 找到底部导航中间红色 `+` 发布按钮并点击。
- 若出现半屏发布类型面板，根据任务选择：
  - 文字笔记：选择“写文字”或类似入口。
  - 图文笔记：选择“从相册选择”或图片入口。

小红书 9.38 的半屏面板从上到下依次是：
1. 最上方第一行 `从相册选择`。
2. 第二行 `相机`，下方有 `拍摄与直播` 说明。
3. 第三行 `写文字`。
4. 最下方 `取消`。

有图任务必须点击**最上方第一行** `从相册选择`，不能把它误认为面板标题后去点第二行相机。坐标只用于当前截图判断，不能记忆固定位置。

误入相机的纠错状态机：
- 出现相机权限、麦克风权限或拍摄取景器，说明路径已经错误；相册发帖不需要这些权限。
- 拒绝权限，或使用 `BACK` / 左上角关闭按钮退出取景器，回到发布类型面板后重新截图，再点击最上方 `从相册选择`。
- 同一任务最多纠错一次。已经出现过相机权限或取景器后，禁止再次选择 `相机`、禁止授权相机/麦克风，也禁止在“取景器 → 关闭 → 取景器”之间循环。

验证信号：
- 文字模式：进入文字编辑或封面生成页面。
- 图文模式：进入相册选择页或素材选择页。

### 2. 必须先判断“有图”还是“无图”
- **有图分支**：任务中存在明确的图片素材/相册文件时，才选择“从相册选择”，按用户指定顺序勾选图片，再进入正式发帖页。若任务说有图片但相册里找不到对应素材，`INFO` 询问，不能随便选手机里的其他照片。
  1. 勾选后先核对右上角按钮中的数量，例如单图任务必须显示“下一步(1)”，数量不符时不能继续。
  2. “下一步(N)”只点击一次。点击后即使下一张截图仍像相册页，也先 `WAIT value:2` 等页面切换；不要再次点击同一坐标，因为新页面该位置可能已变成“拼图/一键成片”等功能。
  3. 正常路径不需要“拼图”“一键成片”或模板加工。若误入这些页面，立即 `BACK` 回到素材选择页或正式发帖页，不要点勾号、完成或继续生成。
  4. 到正式发帖页后，必须再次核对顶部素材缩略图数量与用户指定数量完全一致。单图任务只能有一个缩略图；出现两个缩略图、`1/2` 或重复/拼接封面都代表路径错误，必须回退重选，禁止填写并发布。
  5. 首次进入正式发帖页时，小红书可能弹出“申请获取您的相册内容位置信息”。这是可选的地点推荐授权，不是选图失败：除非任务明确要求读取照片地点，否则点击“取消”；不要点击“同意”，也不要因此重新选择图片。
  6. 若任务只要求验证带图草稿链路，看到顶部素材数量正确、标题和正文输入区以及最终“发布”按钮后，立即 `COMPLETE`。不要点击输入框、地点推荐或最终发布按钮。
- **无图分支**：没有图片素材时必须选择“写文字”，不要误选相册。
- 如果相册为空或没有权限，`CALL_USER`。

### 2.1 未完成草稿恢复弹窗
- 冷启动时可能先出现 `继续编辑图文笔记吗？`，可见 `存草稿`、`去编辑` 和右上角关闭按钮。
- 这是此前未完成内容，不是本次发布入口。无法确认它属于本次任务时，使用 `INFO` 询问，不能自行丢弃、覆盖或进入继续编辑。
- 用户要求继续旧草稿时选择 `去编辑`；用户要求先保留再开始新任务时选择 `存草稿`。
- 只有测试任务明确标识了测试图片/标题，并明确允许清理该测试草稿时，才可点击关闭按钮丢弃匹配的测试草稿。关闭后重新确认已回到首页，再开始本次发布。

### 3. 无图分支是两阶段流程（重点）

选择“写文字”后到达的**不是正式发帖页**，而是“文字生成图片/文字封面”页。必须按下面状态机执行：

1. **阶段 A：生成文字图片**
   - 识别信号：页面中央是大块文字输入区或文字卡片预览，周围有模板/颜色/样式，页面没有正式的“标题”和“正文”两个输入框。
   - 点击文字输入区，只输入适合封面的短句（优先用标题或一句钩子文案），一次 `TYPE` 完成。
   - 验证短句已出现在卡片预览中；可保持默认模板，不要为装饰反复切换样式。
   - 点击本页的“下一步/生成图片/完成”。如果先进入生成后的封面预览，再点一次“下一步”。
2. **阶段 B：正式发帖页**
   - 识别信号：顶部已经有刚生成的文字图片缩略图，同时出现独立的标题输入框、正文输入区、话题/地点等发布设置和最终红色“发布”按钮。
   - 只有看到这些信号后，才能按下面“填写正式内容”流程操作。

文字图片预览页的防误发规则：
- 预览页右下角“下一步”只能点击一次。点击后即使紧接着的截图仍显示预览页，也必须先 `WAIT value:2`，禁止立即重复点击同一坐标。
- 原因是页面可能在截图后、动作执行前完成切换；同一坐标在正式发帖页会变成最终“发布笔记”按钮。重复点击可能直接公开发布。
- 等待后重新截图；只有仍明确显示模板选项和“预览”标题时才能再次点击“下一步”。一旦看到标题/正文输入区或最终“发布笔记”，立刻按阶段 B 处理。

防卡规则：
- 阶段 A 输入文字后截图变化不明显时，先检查文字是否已显示、键盘是否遮住按钮；收起键盘或向下查看一次，不要反复对同一输入框 TYPE。
- 没看到标题/正文两个输入框，就仍在阶段 A；不要把封面短句误当成正式正文，也不要提前 COMPLETE。
- 有图分支不会经过阶段 A，选完相册素材后先等待页面切换，再验证是否进入阶段 B 和素材数量是否正确。
- 相册地点信息弹窗会遮住阶段 B。点击“取消”后重新截图，不要在遮挡时盲点。

### 4. 填写正式内容

**铁律：TYPE 是「整体替换」不是「追加」。同一个输入框只能 TYPE 一次——对已有内容的框再 TYPE 会把原内容清空覆盖。** 所以正文和话题必须**拼成一段、一次性输入**，绝不能填完正文再单独 TYPE 话题（那会清空正文）。

基础顺序（每框只输入一次）：
1. **标题**：点击标题输入框 → `TYPE value:"标题文案"`（标题不含话题）。
2. **正文 + 话题**：点击正文输入框 → 把正文和所有话题拼成**一段文本一次性** `TYPE`，话题用 `#话题文案` 格式、放在正文末尾，多个话题用空格隔开。
   - 例：`TYPE value:"今天去望京打球，水平不错的搭子可以约～\n#羽毛球 #望京羽毛球 #找搭子"`
   - **不要**先 `TYPE 正文` 再 `TYPE #话题`——第二次会覆盖清空正文。
   - **不要**为加话题去点 `#话题` 按钮后再单独输入——同样会破坏正文。直接把 `#话题` 文本写进上面那一段即可。

#### 平台推荐话题的选择流程

当用户明确要求“选择页面推荐话题”或任务指定了当前页面可见的推荐话题时，允许使用正式发帖页正文框下方的推荐话题标签：
1. 标题仍然只 `TYPE` 一次。
2. 正文框只 `TYPE` 一次，这次先输入正文，不要把待选择的推荐话题重复写入正文。
3. 收起键盘或调整页面，让推荐话题标签完整可见；按文字精确匹配目标标签，例如 `#vibecoding`，只点击一次。
4. 重新观察正文区域，只有目标 `#话题` 已出现在正文中，才算选择成功。不得因为页面变化不明显而连续点击标签。
5. 若正文中没有出现目标话题，允许重新展开推荐区检查一次；仍无法确认时报告“话题选择状态未确认”，不要再次 `TYPE` 正文，也不要发布。

推荐话题由账号、正文和当前平台策略动态生成，不同设备上可能不同：
- 用户只要求“选择一个相关话题”而没有指定名称时，只从**当前屏幕已经可见**的推荐标签中选择一个与正文直接相关的标签，点击一次并验证已插入正文；不要为了寻找更理想的话题横向反复滑动。
- 用户指定了精确话题时，先检查当前可见推荐标签，最多再横向查看一屏。仍未出现就停止查找并报告；不得持续滑动直到耗尽步骤。
- 用户允许直接添加已知话题时，优先把正文和 `#话题` 合并为一次 `TYPE`，不要依赖动态推荐区。

`#话题` 工具按钮可能只会聚焦正文，不等同于独立选择页。已知话题使用“一次性正文 + 话题文本”；平台推荐话题只点当前可见且匹配的标签。

验证信号：
- 标题已填、正文框里能看到正文 + 末尾的 `#话题`。
- 使用推荐话题流程时，正文中能看到刚选择的目标 `#话题`，且原正文仍存在。
- 页面出现“发布”“发布笔记”或下一步按钮。
- 若发现正文被清空（只剩话题或只剩标题），说明对同一个框 TYPE 了第二次——重新点正文框，一次性把「正文+话题」整段重新输入。

### 5. 发布或停在确认页
- 如果用户明确要求发布并已确认，点击红色“发布”或“发布笔记”。
- 如果用户没有明确确认，使用 `INFO value:"内容已填写，是否确认发布？"`。
- 点击发布并返回首页只代表提交动作结束；如果任务要求验收，进入“我”并按标题/封面唯一匹配，打开详情核对标题、正文和话题后再报告成功。

### 6. 发布后验证与删除
- 验收已发布笔记时，进入“我”并按标题、封面和正文唯一匹配，打开后核对标题、正文、话题和素材数量。
- 用户要求删除测试笔记时转交“我与账号维护”子技能；删除前必须再次确认目标和最终删除影响，不在发布流程中按坐标猜删除入口。

## 失败处理
- 内容审核失败：`ABORT value:"失败：内容审核未通过，请修改内容"`。
- 图片上传失败：等待后重试一次，仍失败则报告网络或素材问题。
- 用户取消：`ABORT value:"用户取消，草稿可能已保存"`。
