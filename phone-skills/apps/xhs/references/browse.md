# 浏览推荐子技能

适用任务：用户要求刷小红书、看推荐、逛首页、浏览某个分类，或**浏览搜索结果的前 N 篇笔记**。

## 目标
进入目标列表（首页推荐流或搜索结果），按要求浏览内容；当任务给出数量目标（如“前10篇”）时，逐篇打开浏览并精确计数。

## 浏览 N 篇笔记（像真人一样有选择地逛 + 记账，不机械扫格子）

当任务是“浏览前 N 篇/条帖子”时，**目标是看够 N 篇，而不是把结果页从上到下挨个点**。按下面的闭环执行，**一次只处理一篇**：

1. **凭兴趣挑一张**还没看过的卡片点进去：优先点高赞、标题吸引人、封面好看的；可以跳过不感兴趣的；不要永远按网格顺序一行行点。挑之前先确认它的标题**不在** key_process 的已浏览清单里。
2. **在详情页真正浏览一会儿**（不要一进去就立刻 BACK，那不像真人）：
   - 图文帖：先 `action:WAIT value:"1"` 停一下，再 `action:SLIDE point1:500,800 point2:500,300` 下滑看正文；多图时可横向 `action:SLIDE point1:750,500 point2:250,500` 翻一两张配图；继续下滑看几条评论。整篇 2–4 个动作即可，不必看到底。
   - 视频帖：进入的是全屏竖向视频流，先 `action:WAIT value:"2"` 看一会儿视频再返回。
3. 看完用 `action:BACK` 返回列表。
4. 在 key_process 追加这一篇：`已浏览 i/N：<标题或作者>`，保留完整清单，例如
   `key_process:已浏览 3/10：1.北京羽毛球搭子 2.羽毛球脱单局 3.正确握拍vs错误握拍`。
5. **返回后先滑动让看过的卡片离开屏幕**，露出新内容，再挑下一张。重复直到清单计数达到 N，然后 `COMPLETE return:"已浏览N篇：<清单>"`。

铁律（防止重复点进同一篇）：
- **判断“看过没有”只看 key_process 清单，不靠记忆、不靠数滑了几屏。** 标题/作者已在清单里就是看过了，必须跳过，哪怕它很显眼（高赞）反复出现在屏幕上。
- 返回列表后小红书保留原滚动位置，**刚看过的那篇还在原位**——所以第 5 步要先滑动换一批再选，不要就近点最顺手的。
- **如果点击后截图没变化（还在原来的页面/还在同一篇详情页），不要重复点同一个坐标**——说明点空了或点到非卡片区域，改为先滑动、再瞄准新卡片的封面中心点。
- 数量没达标前不要 COMPLETE；达标后不要继续滑。

## 视频帖（沉浸式竖滑流，务必识别）

点开**视频卡片**后进入的是**全屏竖向视频流**（类似抖音），此时：
- 上下滑动是“切换上一个/下一个推荐视频”，**会离开搜索结果**，不是翻列表。
- 因此在视频页**不要用 SLIDE 切换视频**；`action:WAIT value:"2"` 看一会儿后，用**一次 `action:BACK`** 退回原来的列表，再按上面的闭环选下一张。
- 判断自己在视频沉浸流的信号：全屏播放、右侧竖排点赞/评论/收藏图标、没有顶部搜索框和分类标签。

## 普通浏览（无数量目标）

### 1. 回到首页推荐流
- 如果当前不在小红书，先 `action:AWAKE value:"小红书"`。
- 如果当前是“购物 / 消息 / 我”等一级页面，且底部导航确实可操作，点击左下角“首页”。
- 如果顶部有返回箭头、搜索词、搜索输入框、“历史记录”或“猜你想搜”，说明仍在搜索子页面。此时底部导航即使隐约可见也可能只是下层页面，点击“首页”不会生效；应优先点左上角返回箭头或执行 `BACK`，每次只退一层并根据新截图继续判断。搜索结果页通常先退到搜索输入/历史页，再退一次才到首页。
- 点击底部“首页”一次后页面完全不变时，禁止在同一坐标重复点击；改用返回箭头或 `BACK` 退出当前子页面。
- 若已经在瀑布流列表，不要重复返回或重复点击首页。
- 顶部“发现”是底部首页内部的默认频道。看到底部“首页 / 市集 / + / 消息 / 我”和双列瀑布流时，即使顶部选中“发现”也已经在首页；不要为了让“发现”文字消失而反复点击底部首页。

验证信号：底部完整导航可见，页面显示多列瀑布流笔记卡片，卡片含图片、标题、作者或点赞数；顶部可正常选中“发现”。

如果用户只要求“打开/确认首页”，满足上述验证信号后必须立即 `COMPLETE`，不要再点击、滑动或继续探索。

### 2. 选择分类
- 仅当用户明确指定分类时执行（美食、旅行、穿搭、咖啡等）。
- 在顶部横向分类标签中寻找匹配项；找不到时横向滑动标签栏，不要上下滑整页找分类。
- 连续找不到两次时跳过分类，直接浏览综合内容。

### 3. 浏览内容
- 向上滑动浏览下一屏：`action:SLIDE point1:500,850 point2:500,250`。
- 用户只要求“看看前几条”时，不要无限滑动；观察当前屏幕可见卡片即可。
- 对某条感兴趣或任务要求打开笔记时，点击对应卡片进入详情。

## 失败处理
- 页面空白或加载失败：等待 3-5 秒后重试一次。
- 卡在详情页：优先点左上角返回或 `BACK` 回到列表。
- 出现登录页或账号异常：`CALL_USER`。
