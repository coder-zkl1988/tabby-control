# 评论任务子技能（发一条人工审核通过的评论）

适用任务：任务文本以「小红书评论任务」开头。这类任务由桌面端在运营**逐条批准**后生成，任务里给出目标笔记的标题、作者和**唯一允许发送的评论原文**；手机端策略同时只放行这一条原文——改一个字、评别的帖子、多发一条都会被机械拦下（`POLICY_COMMENT_*`）。你的职责是把这条原文准确地放到指定笔记下面，并如实汇报。

## 一、只做这一件事
- 一次任务只发**一条**评论，评在任务指定的那篇笔记下。
- 评论文字 = 任务里给出的原文，逐字 `TYPE`，**不加表情、标点、空格，不换行，不改字**。看到输入框里的字和原文有差别就清空重输，不要"顺手润色"。
- 全程不点赞、不收藏、不关注、不回复他人评论、不私信、不分享（本任务不做互动）。

## 二、找到目标笔记
1. 首页右上角放大镜 → `TYPE` 任务里的笔记标题（原文）→ 搜索。
2. 在结果里找**标题一致且作者一致**的那篇（作者名在卡片下方/详情页顶部核对）。同名不同作者不算；只找到相似标题也不算。
3. 翻两屏还找不到 → 记 `post_not_found`，**不要**评任何别的帖子，直接进入"结束"，status 写 `skipped`。

## 三、评论
1. 进入详情后先 `WAIT value:"2"`，慢滑看正文 5–10 秒（1–2 次 `SCROLL direction:down` + `WAIT`），像看完再评。
2. 点底部评论输入框（「说点什么…」）。如果弹出的是键盘 + 输入框，先看清光标在评论框里。
3. 用**一次** `TYPE` 输入原文；`WAIT value:"1"` 后核对输入框内容与原文一致。
4. 点「发送」。`WAIT value:"2"`，在评论区找到**自己的昵称 + 这段原文** → 算 `sent`。
5. 出现「评论失败」「操作频繁」「内容违规」「请稍后再试」等提示 → 记 `comment_failed` 并把提示原文写进 detail，**不要重试、不要改字重发**，status 写 `failed`。
6. 一次 `BACK` 回列表，再按通用规则回到桌面。

## 四、异常（只能用这几个 type）
| type | 何时 | 处置 |
|---|---|---|
| `post_not_found` | 搜不到标题+作者都一致的笔记 | skipped，结束 |
| `comment_failed` | 发送后未出现在评论区，或有失败提示 | failed，结束 |
| `login_required` | 登录页/验证码 | skipped，立即结束，不要登录 |
| `account_restricted` | 账号异常/受限提示 | skipped，立即结束 |
| `rate_limited` | 操作频繁/稍后再试 | 若已发送算 failed，否则 skipped；立即结束 |
| `interrupted` | 弹窗/来电/被切走 | 按实际情况写 status |

## 五、结束与 COMMENT_JSON（桌面端只认这一行）
`COMPLETE` 的 `return` 先写 2–3 行人读汇报（找到了哪篇、发了没、看到什么提示），**最后一行**必须是 `COMMENT_JSON:` 紧跟一行紧凑 JSON，之后不再写任何字：
```
COMMENT_JSON:{"v":1,"status":"sent","detail":"评论区已出现，位于第 2 条","anomalies":[]}
```
- `status` 三选一：`sent`（评论已出现在评论区）/ `failed`（尝试了但没成功）/ `skipped`（没有尝试）。
- 没发出去就不能写 `sent`；桌面端会用点击回执交叉核对，虚报会被判 failed 并留痕。
- `anomalies` 是 `{"type":"…","detail":"…"}` 数组，没有就 `[]`。
