# 热搜与热帖采集子技能

适用任务：查看当前热搜/热门话题，寻找高热度笔记，并采集标题、正文、互动数据和图片线索返回桌面端。

## 先定义采集目标
- 用户给出数量时严格按数量执行；未给数量时默认采集 3 个热搜话题、每个话题 1 篇代表性热帖。
- 在 `key_process` 维护两层账本：`话题 i/N` 和 `已采集帖子 j/M：<标题>`，不得重复打开同一篇。
- “热门”必须有当前页面证据，例如热搜榜排名、热度标识，或结果页明显较高的赞/藏/评数据；没有证据时写“当前页面未显示热度依据”，不要编造。

## 1. 找到当前热搜
1. 回到小红书首页，点击右上角放大镜。
2. 在搜索落地页寻找“热搜榜 / 搜索发现 / 大家都在搜 / 热门话题”等区域。
3. 某些版本没有完整“热搜榜”，只在“猜你想搜/搜索发现”中给个别词条显示红色“热”或“新”徽标。**带明确“热”徽标的词条可以作为当前热门候选**，热度证据必须写成“搜索落地页热标”，不能伪造榜单排名；无徽标的普通联想词不能当热搜。
4. 键盘遮住下半页时先收起键盘再检查完整区域；若只看到历史搜索和无徽标联想词，向下查看一次。既没有榜单也没有任何明确热度徽标时，才报告当前版本未展示可验证的热搜入口。
5. 选择话题时优先：完整榜单的高位非争议话题 > 带“热”徽标的非争议词条 > 带“新”徽标的词条。记录可见话题文字、排名（若有）和热度标识，然后逐个处理。

## 2. 从话题进入代表性热帖
1. 点击目标话题进入结果页，确认顶部关键词和综合/最新/图文/视频等标签已出现。
2. 优先选择与话题直接相关、互动数据较高的普通笔记；跳过广告、直播入口和明显无关内容。
3. 进入详情后先停留并阅读，再下滑查看完整正文和可见互动数据；多图笔记横向翻图并精确记录图片序号。
4. 任务要求把图片反馈到桌面时，每张图先切到单图大图状态，等待清晰加载；尽量轻点隐藏操作栏，确认当前只显示这一张目标图后执行 `CAPTURE_ARTIFACT value:"<话题>-<标题>-图k-of-T"`。只有下一步历史出现 `ARTIFACT_UPLOADED` 才算该图已采集。

## 3. 采集字段
每篇至少记录：
- 话题、笔记标题、作者。
- 页面可见的点赞/收藏/评论数据；看不清就写“未显示”，不得猜数。
- 正文要点或可见原文片段、话题标签。
- 图片数量和每张图片的内容摘要；每翻到一张图都在 `key_process` 记 `图 k/T：<摘要>；产物：<名称/未要求上传>`。

## 4. 图片与桌面回传边界
- `CAPTURE_ARTIFACT` 会把当前单图页面截图保存为桌面端任务产物；它是可持久化的图片文件，但仍是屏幕采集图，不是小红书原始图片文件，不要声称已获得原图。
- 只有用户明确要求保存且页面提供“保存到相册/保存图片”时，才可以尝试保存；不要通过分享给联系人来转存。
- 如果用户明确要求无界面遮挡的原图，使用 `INFO value:"当前只能回传屏幕采集图，无法保证获得平台原图"`，不要伪造图片链接。

## 5. 完成格式
达到目标后返回结构化结果：
`COMPLETE return:"话题1：...；热帖：标题/作者/互动数据/正文要点/图片摘要；桌面产物：N个（名称列表）；话题2：..."`

出现登录、风控、内容不可见或网络错误时，明确报告具体话题和失败位置；不要因为一篇失败而丢掉已经采集的账本。
