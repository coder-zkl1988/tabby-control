# 养号子技能（搜索 → 浏览 → 选择性互动）

适用任务：用户要求“养号”“日常互动”“涨粉互动”，或“搜索某关键词后对感兴趣的帖子点赞/收藏/评论”。

## 目标
像真人一样按关键词浏览内容，对其中**真正感兴趣的少数帖子**选择点赞、收藏、评论或组合动作，行为自然、有节制，避免触发风控。

## 先定本次目标（开放任务必须自己量化，否则没有结束标志）
养号是开放任务。如果用户**没有**给出明确数量，开始前在 key_process 里给自己定一个人类尺度的目标并据此结束，例如：
`本次目标：浏览约 8–12 篇，其中挑 3–5 篇互动；已浏览 0，已互动 0`。
- 开放任务的结束标志是达到自定的浏览下限和互动目标；达到后立即 `COMPLETE`，汇报浏览了几篇、对哪几篇做了什么。
- 用户给了明确数量（“浏览10篇”“点赞5个”）时，以用户的为准。
- 每完成一篇就更新这两个计数，随时知道还差几次互动。

## 有精确数量时必须先排互动槽位（不可把互动拖到最后）

当用户同时给出总浏览数 `B`、互动篇数 `I` 或各动作组合配额时，在打开第 1 篇前就把计划写入 `key_process`，并在整次任务中保持不变：

- 先确定纯浏览预热篇数（用户指定优先，否则通常为前 2 篇），再把 `I` 个互动槽位**均匀分散**到剩余编号中。只要可用篇数允许，任意两个互动槽位之间必须至少隔 1 篇纯浏览，不能相邻，也不能堆在最后。例如 `B=8、I=3、前2篇纯浏览` 时固定为第 3、5、7 篇；`B=4、I=2、前1篇纯浏览` 时只能选第 2、4 篇，不能选第 2、3 篇。
- 互动槽位属于这 `B` 篇本身：必须在该篇正文和评论读完后、返回列表前完成互动。**严禁先把 B 篇全部记成仅浏览，再回头重进旧帖子补互动。**
- 如果用户指定了“一篇只点赞、一篇只收藏、一篇点赞+收藏”等组合，排程时就把每个组合绑定到具体槽位；后续不得因忘记而全部改成仅浏览。
- 帖子不相关、广告、直播、打不开或不适合互动时，在计入“已浏览”前退出并换一篇；换帖不消耗原互动槽位。
- 每篇结束时都保留同一格式的账本：`已浏览 x/B；已互动 y/I；下一互动槽位：第 n 篇=<动作组合>；已处理：标题[动作]`。不要只写模糊的“稍后互动”。
- 每次决定是否返回前做配额保护：`还需互动 = I-y`，`剩余可处理篇数 = B-x`。当前篇是计划槽位，或“还需互动 >= 剩余可处理篇数”时，本篇必须执行尚缺的互动组合后才能返回。
- 精确数量任务只有在**浏览数、互动篇数和每种动作组合配额全部满足**后才能 `COMPLETE`；任一项不足都不能声称完成。

## 整体流程

1. **搜索**（用户给了关键词时）：进搜索入口 → 用 `TYPE` 输入用户任务里的**实际关键词**（例如任务是“羽毛球”，就输出 `TYPE value:"羽毛球"`；绝不能输入字面量“关键词”）→ 点蓝色“搜索”或 `ENTER`，确认进入结果页（顶部有实际关键词、出现综合/最新/视频/图文标签、下方瀑布流）。没给关键词就在首页推荐流里逛。
2. **有选择地浏览**：凭兴趣挑帖子点进去，优先高赞、标题吸引人、与关键词相关的；任务要求每篇至少阅读 `N` 条评论时，优先选择评论数较多的图文帖，结果页无法判断评论数时也优先图文而不是全屏视频。可以跳过不感兴趣的，不要一行行扫格子。挑之前确认标题不在 key_process 的已处理清单里。
3. **像真人一样浏览详情**（封面停留不算浏览完成）：按下面的“单篇浏览标准”看正文/媒体并进入评论区；只有正文和评论都看过，才把这一篇计入已浏览。
4. **看完后再决定要不要互动、怎么互动**（关键，动作可组合，但不能机械全选）：
   - **多数帖子只浏览、不互动**——看完直接返回，这才像真人。开头第 1–2 篇先纯浏览预热，不要一上来就连着赞。
   - 三种动作**不互斥**：随手喜欢可点赞；值得以后回看可收藏；确实理解内容且有自然观点时可评论。
   - 一种动作最常见；点赞+收藏、点赞+评论等两种组合只用于少数高相关帖子；三种全做只能极少出现，绝不能成为每篇模板。
   - 不要为了凑组合而评论。评论必须针对当前帖子的具体内容，禁止连续发送相同或空泛文案。
   - 不要在连续的帖子上都互动；互动要稀疏、随机、间隔开，像真人偶尔点一下。
5. **执行互动**（按安全规则，见下）：按上一步的决定执行 0–3 个动作，并逐个验证状态变化。
6. **返回并记账**：按“返回结果页纪律”逐层确认页面状态，禁止盲目连续返回。确认回到结果瀑布流后，在 key_process 追加 `已浏览 i：<标题> [赞/藏/评/仅浏览]`，并更新互动计数；先滑动让看过的卡片离开屏幕再选下一篇。
7. 达到本次互动目标（或用户指定数量）后 `COMPLETE`。

## 单篇浏览标准（每篇必须执行）

1. **先看首屏**：进入详情后的**第一个动作必须是** `WAIT value:"2"`，确认标题、作者和主要内容；即使首屏已经加载清楚，也不能用 `SLIDE`、点赞或返回替代这次停留。
2. **阅读正文或媒体**：
   - 图文帖：有“展开”且正文被折叠时先展开；按正文长度做 1–3 次**慢速向上滑动**（手指从屏幕下方向上划，每次后 `WAIT value:"2"`），阅读正文。多图与内容强相关时可横滑查看 1–3 张，不要求机械翻完所有图片。
   - 普通详情布局的视频帖：先观看约 5–12 秒，再慢速向上滑到正文和评论区。
   - **全屏竖向视频流是特殊状态**：底部有心形、星形和评论气泡时，竖向 `SLIDE/SCROLL` 会切换视频，绝不能用它进入评论区。要求至少 `N` 条评论且首屏显示“抢首评”或评论数小于 `N` 时，立即判为不合格：**不要点击评论气泡、评论文字或输入框**，系统 `BACK` 一次返回结果页并另选。评论数达标后，才点心形、星形右侧的**评论气泡中心**；出现列表后在列表内慢滑。
   - 误出现键盘、大片“留下你的想法吧”和粉色“发送”按钮，说明进入了评论编辑器。无评论任务时禁止 `TYPE` 和发送，立即系统 `BACK` 一次，等待回到视频页后只重试评论气泡一次；再次误入就放弃该帖且不计数。
3. **进入并阅读评论区**：继续慢速向上滑，直到屏幕明确出现多条用户评论；任务指定每篇至少 `N` 条时必须读到 `N` 条，否则至少阅读 3 条，并根据评论长度再慢滑 1–2 次。若当前帖不足任务要求的 `N` 条，它不计入已浏览、不消耗互动槽位，返回结果页另选高互动帖子；只有任务未指定下限时才记录实际数量。不要点评论者头像或进入其主页。
4. **节奏要随内容变化**：短正文可少滑，长正文或讨论热烈的帖子可多停留；单次停顿可在 1–4 秒间变化。不要每篇都使用完全相同的坐标、滑动次数和停顿节奏，也不要无目的地一直滑到底。
5. **完成判定**：只有已经看过正文/媒体且满足任务要求的评论阅读数，才在 key_process 中记 `已浏览 +1`。如果评论不足，或误入广告、直播、用户主页、评论编辑器或页面加载失败，返回列表且不计数。
6. **互动时机**：根据正文和评论决定点赞、收藏或评论；完成所选互动后自然停留片刻，再按下面的“返回结果页纪律”返回。

## 返回结果页纪律（防止多退一层）

- 普通图文详情中向上滚动看到的评论仍在同一页，结束时执行一次系统 `BACK`；不要点击左上角返回箭头。
- 全屏视频的评论列表是覆盖在视频上的独立面板：已经打开评论面板时，先系统 `BACK` 一次关闭面板，确认回到视频详情，再系统 `BACK` 一次返回结果页。评论数不足且从未打开评论面板时，只系统 `BACK` 一次就应回到结果页。每次返回后都必须看新截图，禁止混用左上角坐标点击和系统返回，禁止盲目双击返回。
- 返回后必须先 `WAIT value:"2"`，再依据新截图判断。看到顶部搜索词、`全部`、`综合`和帖子瀑布流，才算回到搜索结果页。
- 看到“历史记录”“猜你想搜”或历史关键词胶囊，说明已经多退一层，禁止 `COMPLETE`。点击本次原关键词的历史记录重新进入结果页，确认瀑布流后再继续或结束。
- 截图还在帖子正文或评论区时，说明返回尚未生效；先 `WAIT value:"2"` 复查，只在确认页面仍未变化后补一次系统 `BACK`，不要用左上角坐标点击和系统返回混用。

## 互动动作（详见互动子技能）
- **点赞**：找心形图标点击，验证变红；已红视为完成。
- **收藏**：找星形/收藏图标点击，验证高亮；已高亮视为完成。
- **评论**：点评论图标或底部“说点什么...” → `TYPE` 评论内容 → 点发送，验证出现自己的评论气泡。

## 安全与节制规则（养号关键）
- **点赞、收藏可直接执行**。评论会对外产生影响：任务明确授权“养号并自主评论”时，可基于帖子具体内容生成一句简短自然评论；任务未授权评论且没给评论文案时，先 `INFO value:"要对《标题》评论什么内容？"`。
- **禁止套话开头**：生成的评论不得以“感谢分享~”“感谢分享”“感谢楼主~”等固定寒暄语起手，也不要每条都用同一句式收尾（比如都缀一个“~”）。开头直接接内容本身——具体信息、感受、疑问或吐槽都可以，不同帖子之间的开头和句式要有变化，读起来像真人随手打的字，不是模板。
- 任务明确禁止评论时，搜索词提交后禁止再执行任何 `TYPE`；误入评论编辑器只能返回，不能输入测试文字。
- 自主评论不得包含广告、引流、联系方式、攻击性内容，也不能假装亲身经历；无法理解帖子时不评论。
- **节制与拟人**：多数帖子只看不互动；不要连续每篇都互动，更不要默认三种动作全点；不在同一篇重复操作；节奏放慢。
- 出现“操作过于频繁”“请稍后再试”等风控提示：立即停止互动，`ABORT value:"已触发频率限制，停止养号"`，不要硬刚。
- 登录页 / 账号异常 / 验证码：`CALL_USER`。

## 防重复（沿用浏览纪律）
- 判断“处理过没”只看 key_process 清单，标题/作者重复出现就跳过，哪怕它是高赞反复出现在屏幕上。
- 点击后截图没变化（还在同一页），不要重复点同一坐标，先滑动再瞄新卡片封面中心。
- 视频帖进入的是全屏竖向视频流：先观看当前视频，再**点击评论气泡图标中心**查看当前作品评论；在评论面板打开前禁止任何竖向 `SLIDE/SCROLL`。看不到或看不够任务要求的评论时退出且不计作完整浏览。
