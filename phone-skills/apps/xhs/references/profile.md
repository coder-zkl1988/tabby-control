# “我”Tab 与账号内容维护子技能

适用任务：查看或修改个人资料、维护自己发布的笔记/帖子，以及探索“我”页当前可操作入口。

## 已验证的真机入口
- 小米 Android 16、小红书 9.38.0 的“我”页已看到：`编辑主页`、扫码、分享、浏览记录、钱包，以及笔记/收藏/赞过等内容区。
- 左上角菜单还包含创作者中心、我的草稿、我的活动、浏览记录、我的下载、订单、购物车、钱包、小程序、瞬间、帮助与客服和设置。草稿、浏览记录、下载与创作者能力转交创作者子技能；订单、购物车和钱包转交市集与交易子技能。
- `编辑主页` 已看到：名字、小红书号、实名认证、背景图、简介、性别、生日、地区、职业、学校、原创信息。头像入口通常位于页面顶部；必须按当前截图重新确认，不能把“背景图”当作头像。
- 当前账号自己的笔记详情页通过右上角分享箭头打开操作面板；横向滑动底部操作行后已看到：复制链接、生成分享图、引用发笔记、建群分享、保存图片、编辑、权限设置、薯条推广、合作码、置顶、删除。
- 这些名称是已验证基线，不是固定坐标。页面版本变化时只按当前截图文字操作。

## 总体安全规则
- 修改名字、头像、背景图、简介等会改变公开资料，必须有用户明确给出的新值/目标素材；缺少时 `CALL_USER`，不得猜测或自行润色。
- 删除笔记是不可逆或高影响操作：定位到目标并打开删除确认框后，必须 `CALL_USER value:"已定位到《标题/可见摘要》，确认删除这篇笔记吗？"`；只有收到明确确认才点击最终“删除”。
- 小红书号、实名认证、原创信息可能涉及修改次数、身份材料或提交审核，不按普通表单处理；必须由用户单独明确要求，并在修改次数提示、证件录入、协议或最终提交页 `CALL_USER`。
- 不修改绑定手机号、密码、账号安全设置，也不注销账号，除非用户单独明确要求并在关键确认页人工接管。
- 只操作当前已登录账号自己的内容。发现未登录、账号异常或当前账号与用户描述不符时停止并 `CALL_USER`。
- 不在日志、`key_process` 或最终返回中记录小红书号、生日、地区、学校等资料具体值；只记录“字段已修改/未修改”。
- `收藏`、`赞过`、草稿和浏览记录可能是仅账号本人可见的隐私内容，只返回任务所需摘要，不批量回传完整列表。

## 1. 进入并识别“我”页
1. 使用 `action:AWAKE value:"com.xingin.xhs"` 打开小红书。
2. 能看到底部导航时点击最右侧“我”；若有弹窗先按全局规则关闭。
3. 验证页面有头像、名字、关注/粉丝/获赞与收藏、`编辑主页` 或作品区域；出现登录入口则转交登录子技能。
4. 先观察当前版本实际入口，不按固定坐标盲点。修改资料只进入头像附近的 `编辑主页`，不得点击底部中央“+”；“+”是发布入口，会打开相册而不是资料表单。

## 2. 修改个人资料

执行顺序：进入 `编辑主页` → 识别目标字段 → 只修改一个字段 → 保存或确认自动保存 → 返回“我”页验证 → 再处理下一个字段。

### 名字
1. 点击“名字”，确认进入文本编辑页。
2. 点击输入框后只执行一次 `TYPE`，用用户原文整体替换当前值；同一输入框不得先后 `TYPE` 两次，不追加空格、表情或说明。
3. 点击“保存/完成”。遇到修改频率、字符、敏感词或审核限制时停止，返回页面原始提示，不自动换名。
4. 返回“我”页，只确认展示已更新，不在结果中复述名字。

### 头像与背景图
1. 修改头像时点击 `编辑主页` 顶部头像/“更换头像”；修改背景图时只点击“背景图”字段，二者不得混用。
2. 用户未提供明确图片时 `CALL_USER value:"请提供要设置的头像/背景图片"`。
3. 系统请求照片权限时，优先选择“选择部分照片和视频”，只授权目标图片；不得为了继续而授权整个相册。若无法限定目标素材则 `CALL_USER`。
4. 选择用户指定图片后检查裁剪/预览中的主体和方向；目标不一致就取消，不提交。
5. 点击“完成/保存”，返回“我”页验证对应头像或背景图变化。不得通过底部“+”进入发布相册。

### 简介
1. 点击“简介”后只执行一次 `TYPE`，用用户原文整体替换当前简介；用户未明确要求清空时不得置空，也不得擅自改写。
2. 遇到长度或敏感词限制时停止并返回原始提示，不截断或换词。
3. 保存后返回“我”页确认简介区域已更新，不回传简介全文。

### 性别、生日与地区
1. 只在用户明确给出目标值时进入对应字段。
2. 性别：从当前页面提供的选项中选择完全匹配项；没有匹配项时 `CALL_USER`，不得代选。
3. 生日：在日期选择器中逐级选择用户给出的年/月/日；保存前核对一次，结果中不得回传日期。
4. 地区：按页面层级选择国家/省市/地区；有同名或层级不确定时 `CALL_USER`。
5. 若点击选项即自动保存，等待返回 `编辑主页` 后核对字段状态；若有“完成/保存”，只点击一次并等待成功返回。

### 职业与学校
1. 点击“职业”后优先搜索或选择与用户原文完全匹配的分类；没有精确项时列出候选并 `CALL_USER`，不得选最相近项。
2. 点击“学校”后输入用户给出的完整学校名；同名学校必须结合页面可见地区/院校信息让用户选择。
3. 页面继续要求院系、入学时间或证明材料时，仅填写用户明确提供的信息；缺少即 `CALL_USER`。
4. 保存后返回“我”页验证字段状态，不返回职业、学校的具体值。

### 小红书号、实名认证与原创信息
1. 小红书号：先阅读页面的修改次数、格式和生效规则；在最终保存前 `CALL_USER` 复核目标值及次数影响。不可编辑时如实返回。
2. 实名认证：只允许进入入口确认状态；出现姓名、证件、人脸或协议页面立即 `CALL_USER`，不得自动填写或提交。
3. 原创信息：先识别是普通文本/选择器，还是原创声明/资质申请。普通字段仅按用户明确给出的真实目标修改，保存后回读；涉及证明材料、权利声明、授权协议、公开认证或提交审核时，必须 `CALL_USER`，不得代替用户作真实性或版权承诺。

### 保存与验收
- 每次只修改一个字段。页面有“保存/完成”时点击一次；页面自动保存时等待返回列表后再验证。
- 保存前用户取消时执行 `BACK`；出现“保存更改”提示则选择“不保存/放弃修改”，回到 `编辑主页` 核对旧值未变。若选项已自动保存后用户才取消，不得猜测旧值或擅自回滚，`CALL_USER` 说明当前状态。
- 保存后先在 `编辑主页` 回读目标字段；对主页公开展示的名字、头像、背景图、简介，再回到“我”页二次验证。
- 保存失败、结果不确定或页面未返回时不得重复点击；返回 `ABORT value:"失败：资料修改结果未能确认，未重复提交"`。
- 成功返回字段名和状态，例如“名字已修改、背景图未修改”；不得返回敏感字段具体值。

## 3. 查看和管理自己发布的笔记
1. 在“我”页进入自己的“笔记/作品”区域，不要误入“收藏”或“赞过”。
2. 按用户给出的标题、发布时间、封面或正文摘要定位目标；若有多个相似结果，列出可见差异并 `CALL_USER` 让用户选择，不得猜。
3. 打开目标后再次核对作者是当前账号、标题/正文/封面与目标一致。
4. 点击右上角“…”或分享箭头打开操作面板；不要点击底部中央“+”。底部操作行可横向滑动，滑动后重新观察文字。
5. 已验证菜单包括复制链接、生成分享图、引用发笔记、建群分享、保存图片、编辑、权限设置、薯条推广、合作码、置顶和删除；只执行用户明确要求的操作。

## 4. 执行自有作品菜单操作
- **编辑**：点击“编辑”，只修改用户明确指定的标题、正文、图片或标签；进入发布/保存前核对目标笔记和变更内容。保存后返回详情验证，不重复提交。
- **权限设置**：记录当前可见范围，再选择用户明确指定的新范围；选择可能立即生效，操作后重新打开菜单验证状态。
- **置顶/取消置顶**：仅在用户明确要求时点击一次；返回“我”页验证卡片位置或菜单文字已切换。
- **复制链接/生成分享图/保存图片**：仅在用户明确要求时执行；操作后用“已复制/已保存”等提示验证结果，不得把生成结果发送给联系人。
- **引用发笔记/建群分享**：会创建或发送新内容，转交发布/消息流程；未提供收件人和内容时不得继续。
- **薯条推广/合作码**：可能涉及商业推广、授权或费用；只允许查看入口，出现开通、协议、预算、支付或最终提交时 `CALL_USER`。

## 5. 删除自己发布的笔记
1. 严格完成上面的目标定位与二次核对。
2. 打开分享/更多菜单，横向滑动底部操作行找到“删除”；每次滑动后重新观察，不能按记忆点固定位置。
3. 若出现“删除并重新编辑/仅自己可见/删除笔记/取消”等中间面板，仅在目标确为永久删除时选择“删除笔记”，不得用其他选项替代。
4. 出现最终确认框时暂停并 `CALL_USER`；页面文案可能是“确认永久删除作品？”或同义提示，同时说明即将删除的标题或可见摘要。
5. 用户明确确认后只点击一次红色“确认删除”；用户取消则关闭面板并验证笔记仍存在。
6. 删除后等待回到个人主页，验证目标卡片已消失或出现“删除成功”提示。若结果无法确认，不得再次点击删除；返回 `ABORT value:"失败：删除结果未能确认，请人工检查，未重复执行"`。

## 6. 自由探索“我”页
- 用户只要求查看“有哪些能操作”时，仅做只读探索：进入“我”页、编辑资料页和自己笔记的更多菜单，记录当前屏幕实际可见的入口；不要保存修改、切换隐私、退出登录或触发删除确认。
- 返回格式：`COMPLETE return:"当前‘我’页可操作项：个人资料[...]；内容管理[...]；其他入口[...]；受限/需人工确认[...]"`。
- 页面结构随版本和账号状态变化，只有截图中真实出现的入口才能报告为“当前可操作”；未看到的能力写“当前未发现”，不得把本文的常见项当成已验证事实。
