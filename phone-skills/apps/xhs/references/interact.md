# 互动操作子技能

适用任务：点赞、收藏、评论、关注、分享小红书笔记。

## 安全规则
- 点赞和收藏可以直接执行。
- 关注、分享会对外产生影响；如果用户没有明确指定对象，先 `INFO` 询问。
- **评论只能通过「小红书评论任务」发**（见 comment 子技能）：那类任务带有人工审核通过的原文，手机端策略只放行那一条。任何其他任务要求评论——哪怕用户给了文案——都不要去点评论框：`ABORT value:"评论需先经桌面审核队列批准，请在评论审核里生成/批准后派发"`。评论框里的 TYPE 和「发送」在非评论任务里会被策略直接拦下（`POLICY_COMMENT_FORBIDDEN`）。

## 推荐流程

### 1. 打开目标笔记
- 如果当前在首页或搜索结果瀑布流，点击目标卡片进入详情页。
- 目标不明确时，选择最符合用户描述的第一条普通结果；用户要求“最新”时跳过置顶内容。

验证信号：
- 进入笔记详情页。
- 可见图片/视频区域、标题正文、作者信息。
- 右侧或底部有点赞、收藏、评论、分享等按钮。

### 2. 点赞
- 寻找心形图标并点击。
- 验证心形变红或点赞数变化。
- 如果已经是红色，视为已完成。

### 3. 收藏
- 寻找星形或收藏图标并点击。
- 验证图标变黄、高亮或收藏数变化。
- 如果已经高亮，视为已完成。

### 4. 评论
- 本子技能不做评论。只有以「小红书评论任务」开头的任务才能评论，流程与汇报格式见 comment 子技能；其他任务遇到评论要求按上面的安全规则 `ABORT`。
- 需要"看评论"（阅读评论区）时点「评论」气泡进入评论区即可，不要点输入框。

### 5. 关注
- 在详情页顶部作者区域寻找“关注”按钮。
- 点击后验证变为“已关注”或按钮消失。
- 若已经关注，直接 `COMPLETE return:"已关注"`。

### 6. 分享
- 点击分享箭头图标。
- 分享面板弹出后，如果用户没有指定渠道，使用 `INFO value:"分享面板已打开，请选择分享渠道"`。

## 返回
- 互动完成后，如果任务还要求处理下一条笔记，使用返回键回到结果流。
- 如果任务只要求互动当前笔记，完成后可 `COMPLETE return:"已完成"`。
