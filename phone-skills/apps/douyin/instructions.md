## 抖音全局操作指南

本技能只提供抖音 App 内的页面知识和流程策略。你仍必须严格输出 GELab 单行动作格式：
`verify:...\tnote:...\texplain:...\taction:...\tkey_process:...`

### 启动与包名
- 中国大陆抖音包名通常是 `com.ss.android.ugc.aweme`；TikTok 包名可能是 `com.zhiliaoapp.musically`。
- 打开抖音时使用 `action:AWAKE value:"抖音"` 或 `action:AWAKE value:"com.ss.android.ugc.aweme"`，不要依赖桌面图标坐标。
- 页面结构会随账号、地区、灰度实验和版本变化；始终以当前截图中的文字、选中态和控件含义为准。

### 首页结构
- 顶部左侧是侧边栏，右侧是搜索；中间为可横向变化的频道。真机 39.8.0 曾显示“直播 / 北京 / 团购 / 关注 / 商城 / 推荐”。
- 底部通常是“首页 / 朋友 / 拍摄 `+` / 消息 / 我”。“朋友”有时只显示头像或未读角标，不能只靠文字判断。
- 普通视频的作者信息和文案在左下区域；作者头像、点赞、评论、收藏、分享通常在**右侧竖排**。不要沿用“互动按钮在左侧”的旧布局假设。
- 视频可能出现“全屏观看”“相关搜索”“听合集”等内容专属入口；只在任务需要时点击。

### 每个新任务先建立稳定起点
- 已在“首页 / 推荐”且底部完整导航可见时可直接开始，不要重复点击首页。
- 搜索结果通常要先 `BACK` 回搜索输入/历史页，再 `BACK` 一次回首页；每次返回后重新看截图。
- 评论面板点右上角关闭；分享面板点“取消”；侧边栏点右侧遮罩关闭。
- 创作页优先点左上角关闭。若出现“放弃编辑/保留草稿”确认，不要盲点，按任务要求处理。
- 首页视频持续动画导致页面树不稳定时，可先点击视频空白区域暂停，再重新观察；不要把暂停按钮误当互动按钮。

### 状态与风险边界
- 默认只读。没有明确任务时，不点赞、收藏、关注、评论、私信、转发、发布、开播、送礼、加购或下单。
- 点赞、收藏、关注只能在用户明确要求时执行，并先读取“已/未”状态，避免误触成取消操作。
- 评论、私信、分享给联系人、发布作品或开始直播前，必须确认目标账号/会话和最终内容；最终发送或发布后还要验证业务结果。
- 购物、充值、送礼、支付、退款、删除作品、清空历史等资金或不可逆操作，在最终确认按钮前必须 `CALL_USER`。
- 登录、验证码、实名、人脸、CAPTCHA、账号异常或风控页面使用 `CALL_USER`；不要读取、记录或回显敏感信息。

### 弹窗与失败处理
- 更新弹窗选择关闭、稍后或不更新；不要擅自升级。
- 系统权限、相册/文件选择器和输入法由对应系统 Skill 处理。
- 网络错误等待 5 秒后重试一次；仍失败则 `ABORT value:"失败：抖音页面加载失败"`。
- 点击后截图完全不变时，不要重复同一坐标；重新观察控件状态或改用返回键恢复。

### 子技能懒加载
- 浏览、搜索、互动、发布、消息、个人页、直播和商城流程由任务相关子技能提供。
- 若子技能描述与当前截图冲突，以当前截图为准，但不得绕过上述风险边界。
