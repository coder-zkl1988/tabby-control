# 拍摄与发布子技能

适用任务：拍摄、从相册选素材、制作文字/图文/视频作品并发布。

## 进入创作页
1. 回到抖音一级页面，点击底部中央拍摄 `+`。
2. 确认进入创作 Activity，而不是普通视频详情或直播间。
3. 真机 39.8.0 的创作入口曾包含：顶部“选择音乐”；中部“分段拍 / 照片 / 视频”；底部“文字 / 相机 / 创作灵感 / 开直播”；拍摄按钮和“相册”。
4. 右侧工具可能有切换摄像头、闪光灯、设置、动图、灵感跟拍、倒计时、提词器和更多。

## 选择创作方式
- 用户提供本地图片/视频：点击“相册”，交给媒体选择器 Skill；只选用户明确指定的素材和数量。
- 用户要求现场拍摄：选择“照片/视频/分段拍”后再拍，先确认摄像头方向和模式。
- 用户要求纯文字：选择“文字”，按实时编辑器完成内容。
- “开直播”是独立高风险流程，不是发布普通视频；只有用户明确要求开播时才进入直播子技能。
- 任务未说明素材来源或作品类型时，先 `CALL_USER`，不要替用户决定拍摄、相册或文字。

## 编辑流程
- 每次进入新编辑页都重新读取当前截图。抖音编辑器会因内容类型变化，不要把入口页坐标沿用到编辑页。
- 仅设置用户要求的标题/文案、封面、音乐、话题、位置、可见范围等；不要擅自添加营销文案、@账号、位置或音乐。
- 输入后逐字段复核，尤其是输入法建议、自动话题和 AI 改写是否污染原文。
- 若出现原创声明、内容审核、实名、人脸、版权或风控提示，停止并 `CALL_USER`。

## 最终发布边界
- 到最终“发布”按钮前，使用 `INFO`/`CALL_USER` 汇总并确认：账号、作品类型、素材数量、文案、可见范围和目标动作。
- 未收到确认时停在发布前页面，不点击“发布”。
- 点击发布后，等待上传/审核结果；编辑器消失或回首页不等于发布成功。
- 优先进入“我 > 作品”确认新作品或明确的发布成功/审核中状态，再返回结果。审核中必须报告为“已提交审核”，不能说“已发布”。

## 退出与草稿
- 尚未拍摄/选择素材时点左上角关闭通常可直接退出。
- 已有内容时可能出现“保存草稿/放弃编辑”。用户未授权删除内容时优先保留草稿或 `CALL_USER`。
- 不得清空草稿、删除作品或覆盖现有草稿，除非用户明确指定并在最终删除前确认。
