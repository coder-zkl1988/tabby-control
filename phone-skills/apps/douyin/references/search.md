# 搜索与筛选子技能

适用任务：搜索视频、用户、商品、店铺或关键词，并筛选结果。

## 搜索流程
1. 回到抖音首页，点击右上角放大镜“搜索”。
2. 确认顶部出现返回、输入框和“搜索”按钮；下方可能显示历史记录、猜你想搜和热榜。
3. 输入用户要求的实际关键词。输入框有旧词时先点击明确的清空按钮，再 `TYPE`；不要输入“关键词”等占位文字。
4. 点击右侧“搜索”或执行 `ENTER`。
5. 验证顶部仍显示目标词，结果区已加载且不再是历史/猜你想搜页。

搜索会写入账号历史。用户仅要求观察搜索入口时，不输入、不提交。

## 结果分类
真机 39.8.0 的一级分类曾包括：
- 综合
- 商品
- 用户
- 店铺
- 视频
- 图文

右侧还可能有单双列切换和“筛选”。综合页可能显示“全部 / 最新 / 排行榜 / 是什么意思 / 科普”等动态细分词。只按用户意图切换：
- 找博主或账号：选“用户”。
- 找商品/店铺：选“商品”或“店铺”，随后遵守商城子技能的交易边界。
- 只看视频或图文：选对应分类。
- 用户要求最新：选“最新”，并通过时间/排序标识验证，而不是仅凭第一条内容猜测。

## 读取结果
- 普通结果常为双列卡片，含时长、文案、作者、日期和点赞状态。
- 点击卡片进入详情后，完成读取再 `BACK` 回结果列表；不要在详情中上下滑而误入推荐流。
- 处理多条时在 `key_process` 记录已读作者/标题，返回列表后先滑动露出新结果，避免重复。
- 无结果时可精简关键词重试一次；仍无结果则 `ABORT value:"失败：未找到相关结果"`。

## 返回首页
- 结果页执行一次 `BACK` 通常回到输入/历史页。
- 再执行一次 `BACK` 才回首页推荐流。
- 每次返回后重新截图；看到“历史记录/猜你想搜”说明仍在搜索层，不要误报已回首页。
