# 互动操作子技能

适用任务：点赞、收藏、关注、评论、回复或分享当前视频。

## 通用安全规则
- 只有用户明确要求某种互动时才执行；“浏览/看看”不包含任何互动授权。
- 每次先读取当前状态，再决定是否点击。状态不清楚时停止并重新观察，不要用点击试状态。
- 一次动作后立即复核目标状态；失败时不要连续点击，否则可能把成功状态切回去。

## 点赞与收藏
- 普通视频右侧心形通常是点赞，星形通常是收藏。无障碍描述可能直接显示“未点赞/已点赞”“未选中/已选中”。
- 用户要求点赞且当前“已点赞”时直接完成；要求取消点赞且当前“未点赞”时也直接完成。收藏同理。
- 点击后必须看到状态文字、颜色或计数变化，才能报告成功。

## 关注
- 作者头像或作者主页附近可能有关注入口；不要把头像本身当成已确认的关注按钮。
- 明确找到“关注/已关注”状态后再操作，并验证状态变化。
- 取消关注会改变账号关系，用户没有明确说“取消关注”时不得执行。

## 评论与回复
1. 点击右侧评论气泡，确认半屏评论面板打开。
2. 面板可能有“评论 N / AI 解析”、展开回复、评论点赞和底部“发条评论”输入区。
3. 评论点赞也是账号状态变更，不能因为正在读评论而顺手点击。
4. 发布评论/回复前确认目标视频、目标评论和最终文本。必要时 `CALL_USER`。
5. 输入后，在最终“发送”前再次核对文本没有被输入法建议或 AI 改写污染。
6. 发送后看到新评论、回复落位或明确成功提示才算完成；审核中要如实报告。
7. 关闭面板使用右上角 `X`；不要点“放大评论区”当关闭。

## 分享
- 点击右侧分享箭头后，面板先显示最近联系人，下方可能有“转发到日常 / 推荐 / 私信 / 我的群聊 / 帮上热门 / 分享链接”等横向动作。
- 联系人头像是立即发送风险区。用户未明确目标联系人时，不得点击任何头像。
- “转发到日常”“推荐”“私信/群聊”都会产生外部可见结果；最终动作前确认渠道、对象和附言。
- 用户只要求复制/读取链接时，找“分享链接/复制链接”，执行后验证剪贴板或成功提示；不要顺带发送。
- 取消分享面板点右上角“取消”。

## 完成报告
返回具体结果，例如“当前视频已点赞，状态已变为已点赞”；不要只说“已点击按钮”。
