## 企业微信操作指南

### 启动与已验证界面
- 官方包名：`com.tencent.wework`；启动后确认前台包仍是它。
- 一台手机可能有多个企业微信实例（应用分身）：AWAKE 会弹出「使用以下方式打开」选择弹窗，在弹窗中点对应图标即启动指定实例。任务涉及分身、多个实例或“按企业执行”时，先读 [多实例与企业遍历](references/multi-instance.md)。
- 本指南基于荣耀真机上的企业微信 `5.0.9` 验证。租户配置、管理员权限和版本不同会让入口增减，始终以实时截图为准。
- 底部五个主模块依次为：**消息 / 邮件 / 文档 / 工作台 / 通讯录**。
- 消息页顶部常见入口：左侧企业与账号抽屉，右侧搜索和 `+`；快捷栏为**全部 / 日程 / 待办 / 会议**。
- **查企业指派的待办，先看消息列表。** 1v1 群发和客户朋友圈的待办都由企业在企微内指派，并在会话列表里各有一条官方提醒：「群发助手」（摘要形如「管理员通知你群发消息给客户」）和客户朋友圈（摘要形如「通知你发表内容到客户的朋友圈」）。列表上的未读角标直接说明有没有待办，比逐个翻工作台快、也不容易漏；消息列表里没有该条目，才退回工作台入口确认。任务内容就在这些条目里，不需要也不应该去别处找「任务定义」。

### 稳定导航
1. 先识别标题、底部高亮项和当前企业，不凭固定坐标猜页面。
2. 子页面优先点击左上角返回；无响应时刷新截图后再用系统 `BACK`。
3. 弹出菜单、键盘、抽屉可能拦截第一次返回。每次返回后重新观察，不连续盲按。
4. 页面与本指南不一致时，从底部主模块或消息页重新进入目标功能。

### 默认只读与确认边界
- **默认只读**：只浏览列表、打开入口、读取用户明确指定的对象，不主动发送、保存、提交、打卡、邀请或批量触达。
- 消息、邮件、文档、日程、会议、待办、客户资料、审批和汇报属于企业数据。除非任务明确要求，不读取或复述具体姓名、群名、消息、金额、地址、定位、附件和文档正文。
- 到达最终的**发送 / 保存 / 提交 / 打卡 / 确认添加 / 发起会议**按钮前，核对企业、目标对象、正文或表单、附件、时间、参与人和权限；目标或内容有歧义时先询问用户。
- 对外收款、付款/报销/合同、工资条、人事变更、企业创建/加入/退出、管理员设置、删除/撤回、客户群发和大范围邀请必须 `CALL_USER`，不得自主完成。
- 例外：任务明确要求“每个企业都执行”时，允许按 [多实例与企业遍历](references/multi-instance.md) 的协议自主切换企业并在完成后切回；仅限切换，创建/加入/退出仍需 `CALL_USER`。
- 不代填密码、验证码、身份证、银行卡等敏感信息；需要时停在输入页交由用户处理。

### 成功判定
- 点击按钮、出现加载动画或回到列表都不等于成功。
- 消息/邮件要看到目标会话中的新记录且无失败标记；日程/会议要在对应日期或会议列表出现；审批在**已提交**、汇报在**我的**、打卡在结果/记录中可核验；客户或成员操作要在目标列表看到准确对象。
- 若出现审核中、待审批、上传中、定位失败或网络失败，按实际状态报告，不宣称已完成。
