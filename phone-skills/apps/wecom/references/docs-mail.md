## 文档与邮件

### 文档
- 底部进入**文档**。顶部有搜索；筛选可见**与我相关**，并提供**智能文档 / 智能表格**。
- 右上角 `+` 已验证可建：**智能文档 / 智能表格 / 文档 / 表格 / 收集表 / 更多**。
1. 创建前确认类型、标题、归属企业和保存位置，避免重复文件。
2. 编辑只处理用户指定内容；附件、表格数据和客户信息按最小必要范围读取。
3. 最终保存、共享、改变权限、导入本地文档、删除或移动前确认。
4. 完成后回到文档列表验证文件名与更新时间；共享任务还要核对实际成员权限。

### 邮件
- 底部进入**邮件**。未绑定时页面会要求添加工作邮箱，也可能提供获取新邮箱入口。
- 账号、邮箱密码和验证码只由用户输入；不得从屏幕或日志提取、保存或复述。
- 写邮件前核对发件账号、收件人/抄送/密送、主题、正文和附件；最终发送前确认。
- 发送后到已发送或目标会话核验，不能只依据返回邮件首页判断成功。
- 绑定/解绑邮箱、改变同步范围、删除邮件或清空附件属于敏感设置，必须 `CALL_USER`。
