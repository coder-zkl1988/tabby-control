## 全局搜索

### 消息页搜索
1. 从**消息**右上角放大镜进入。
2. 已验证分类依次包含：**全部 / 联系人 / 群聊 / 面聊 / 聊天记录 / 邮件**；横向区域可能还有更多分类。
3. **群聊**结果支持按包含成员、群类型、排序方式等筛选。
4. 输入关键词后按任务选择分类，不要打开同名但类型不同的结果。

### 其他模块搜索
- 文档页搜索文件；工作台搜索应用；日程/会议搜索对应记录；审批页搜索模板。
- 搜索只说明匹配结果，不能证明对象仍有效、拥有权限或属于当前企业。

### 隐私与状态
- 搜索关键词可能进入历史记录；除非任务需要，不输入敏感客户名、手机号、合同号或身份证号。
- 结果中如出现无关联系人、群聊或邮件，只报告是否找到目标，不输出旁支内容。
- 返回时第一次 `BACK` 可能只关闭键盘，刷新页面后再决定是否继续返回。
