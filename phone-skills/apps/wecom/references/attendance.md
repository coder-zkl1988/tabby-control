## 打卡与考勤

### 打卡页
1. 从**工作台 > 打卡**进入。
2. 已验证顶部区分**上下班打卡 / 外出打卡**；中部显示地图、定位和当前打卡按钮。
3. 底部包含**打卡 / 申请 / 统计 / 考勤机**。

### 打卡流程
1. 核对当前企业、日期时间、上班/下班/外出类型、定位状态和班次规则。
2. 不伪造或手工替换定位；定位失败、规则未配置或超出范围时如实报告。
3. 点击最终打卡按钮会写入考勤记录，必须在当前任务明确要求且用户确认后执行。
4. 打卡后查看成功提示、时间和记录；只看到地图或按钮变化不算完成。

### 申请与统计
- **申请**页已验证有**请假 / 出差 / 外出 / 加班**和**申请记录**。
- 选择类型后核对起止时间、时长、事由、证明附件、审批人/抄送人；最终提交前确认。
- **统计**用于查看考勤结果；不要把统计页当作补卡或申诉入口。
- 补卡、撤销申请、修改考勤规则或考勤机配置会影响正式记录，必须 `CALL_USER`。
